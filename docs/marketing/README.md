# Base SEO & marketing réseaux — Fabl

Corpus d’inspiration craft (narrative design / écriture jeux) pour alimenter contenus LinkedIn, Instagram, site et SEO.

## Limite importante

**Instagram et LinkedIn ne sont pas scrapés.** Leurs conditions d’utilisation interdisent l’extraction automatisée ; les outils GitHub type Instaloader / Phantombuster contournent ces règles et exposent le compte / la boîte. Ici on s’appuie uniquement sur :

- articles et blogs publics indexés
- profils / posts LinkedIn **déjà publics et citables** via recherche web
- newsletters / Substack / GDC / Game Developer

Pour la veille quotidienne : suivre manuellement la [watchlist](./watchlist-reseaux.md), ou brancher plus tard les **API officielles** (LinkedIn Marketing Developer Platform, Instagram Graph API Business) avec un compte pro Fabl.

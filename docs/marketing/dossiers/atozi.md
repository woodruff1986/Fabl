## Insights extraits

### Structure adaptée > structure complexe (Frog Detective)
Le jeu ne simule pas l’enquête : clefs/serrures + collecte d’objets = *sentiment* d’enquête. « Un jeu n’a pas besoin d’une structure complexe, il a besoin de la structure adaptée. »

**Hook Fabl :** « On conçoit le sentiment, pas la simulation. »

### Ordre des verbes = philosophie (Planescape)
Fouiller → parler → attaquer. Violence = dernier recours. Parler ouvre d’autres verbes (observer, loot). PNJ = coffres à « fouiller » via dialogue. Skinner box narrative : incertitude de récompense → parler à tout le monde ; puis casse la box hors morgue.

**Hook Fabl :** « L’ordre des verbes raconte déjà le jeu. »

### Cerbère de la porte (Firebird)
Portes abstraites (routes) + ressource-clef (essence). Sans clef = game over / retour. Motive exploration + impose rythme. Ressource parfois compte à rebours auctorial (tension maîtrisée). Outil ND : gameplay + narration imbriqués.

**Hook Fabl :** « Pas de porte sans clé — et la clé force le regard. »

### Narration procédurale interdite si le jeu *est* la narration (Baladins)
Procédural OK si adossé à un système fort (Dwarf Fortress, Sunless Sea). Si plaisir = dialogues / rencontres / voix : écrire fixe. Banques génériques = monde neutre. « La narration procédurale n’est pas faite pour les jeux narratifs. » Vestiges utiles : clefs pour « ouvrir » PNJ.

**Hook Fabl :** « Procédural sans système fort = âme diluée. »

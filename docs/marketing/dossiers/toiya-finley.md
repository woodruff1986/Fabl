## Insights

### Contrary game design
Subversion de mécaniques/scénarios qui **oppose** les attentes joueur (≠ troll gratuit). Mechanics = clichés / métaphores (dialogue trees = face time ; loops = hunting…). Subversion doit être logique, non punitive ; ne pas dicter « la bonne façon de jouer ». Trop fréquent = nouvelle habitude instinctive (*Undertale* Genocide route = timing).

### Player at the heart
Même récit linéaire / interstitial mobile : éviter PC passif. « Play, don’t tell » + **suggérer** (imagination joueur). Game space reflète l’histoire. Agency clé même hors AAA.

## Hooks Fabl
